# Security policy

Please do not open a public issue for a suspected vulnerability that exposes
credentials, grants unintended cloud access, bypasses the image gate, or
permits signature confusion.

Report it privately through GitHub's **Security** tab using **Report a
vulnerability**. Include the affected commit, reproduction steps, expected and
actual behavior, and any known blast radius. Do not include live credentials
or customer data in the report.

This portfolio repository has no guaranteed support window. Security fixes are
applied to the default branch; historical tags and screenshots are evidence,
not maintained release lines.
